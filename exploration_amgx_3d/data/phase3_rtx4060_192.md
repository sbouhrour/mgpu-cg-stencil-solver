# Phase 3 — Validation locale (RTX 4060), grille 192³ 27-point, single-GPU

Matrice : 3D 27-point Laplacian, N=192 → 7 077 888 lignes, 189 119 224 nnz.
Fichier : `matrix/stencil3d_27pt_192.mtx`.
RHS `b = ones`, guess initial `x0 = 0`, tolérance `||r||/||b|| < 1e-6` (norme L2,
RELATIVE_INI). Single-GPU (`-np 1`).

Hardware : NVIDIA GeForce RTX 4060 Laptop GPU (CC 8.9), 8 GiB.

## Région chronométrée

- **AmgX** : `AMGX_solver_solve` seul (reset de x et download hors timing).
- **Custom** : boucle CG (médiane sur 10 runs après 3 warmups).

Les deux mesurent donc le solve pur. Médiane sur les runs valides.

|-----------------|-----------:|------------------:|--------------------|----------------------|:---------:|

GFLOPS AmgX (rapporté) : 18.0. Résidu final custom : 2.37e-3 (absolu ; relatif < 1e-6).

## Vérifications de cohérence

- **Itérations identiques** : les trois convergent en 227 itérations → algorithme
  CG non-préconditionné aligné (même matrice, même critère).
- **Solution identique** : `sum(x)` concorde à ~13 chiffres significatifs entre
  AmgX et custom (6.00055432666e8) ; `norm2(x)` = 2.7729635739e5 des deux côtés.
  → AmgX résout bien la même matrice que le solveur custom.
- **Overlap ≈ Sync à np=1** : attendu — sans partition multi-GPU il n'y a aucun
  halo à recouvrir, le mode Overlap dégénère vers Sync. Le gain Overlap
  n'apparaît qu'à np ≥ 2.

## Lecture

Sur un seul RTX 4060, le solveur custom (Sync) est **~1.48×** plus rapide
qu'AmgX-CG sur cette matrice 27-point (3231 ms vs 4769 ms), à itérations et
solution identiques. Mesure de validation locale — la campagne scientifique
visée est 512³ sur 8× A100 (voir `../README.md`).
